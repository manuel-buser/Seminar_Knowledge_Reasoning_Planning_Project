# AI usage statement

Per the *Wegleitung für die Verwendung von KI in der Lehre* (UK Informatik,
May 2024), §C.ii — *Erstellung von Quellcode*.

**Tool:** Claude Code (CLI, Anthropic), models Claude 4.x Opus / Sonnet,
used April – May 2026. https://www.anthropic.com/claude-code

## My own contribution

- Project idea: rewriting the IPC-2018 Spider domain with PDDL axioms and
  benchmarking against the original on Fast Downward.
- The axiomatic reformulation in [Spider_Axioms/domain.pddl](Spider_Axioms/domain.pddl):
  which predicates to derive (`movable`, `part-of-tableau`), the recursive
  definitions, the stratification check, and which action effects to drop.
- Choice of Fast Downward configurations (`blind`, `hmax`, `lmcut`, LAMA)
- Interpretation of the experimental results.

Quantitative declaration (Wegleitung §C.ii): roughly **90 %** of the code
under [scripts/](scripts/) is AI-generated.

**(b) PDDL syntax debugging** — when the Fast Downward translator rejected
intermediate versions of the axiomatic domain, I used Claude Code to identify
the fixes (e.g., wrong nesting in an
axiom body, type mismatch on a derived predicate). The semantic content of
the axioms is mine.

## What AI did NOT do

- It did not propose the project, the reformulation, or the experimental
  design.
- It did not author [Spider_Axioms/domain.pddl](Spider_Axioms/domain.pddl)
